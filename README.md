# ICM LAB
日本語トーナメントICM・RFI推定アプリ。依存パッケージなし。

公開アプリ: https://kentonov-stack.github.io/icm-lab/
ソース: https://github.com/kentonov-stack/icm-lab

起動: `npm start` → http://localhost:4173
テスト: `npm test`

全員スタック未入力時は推定。9人以上は16,384回の固定乱数Monte Carlo、8人以下は再帰ICM。表示誤差は標本誤差のみ。BFはデッドマネーなしの同額実効スタック勝負。チップ限界価値は±5%の比例移転による中央差分。最大500人。

賞金総額はバイイン×総エントリー数で自動計算（手数料控除なし）。賞金はWSOP Online MTTの傾斜を参考に2位を優勝の60%目安とし、3位以下のウェイトをべき乗変換して総額・両端に合わせる。下位には同額入賞帯を設定。条件に無理があれば2位比率を補正し注意表示。公式賞金表の再現ではない。全員スタックは先頭が自分、総チップとの一致が必要。

RFIはポジション基準頻度とBB・アンティ・ICM圧力・分布幅・平均比率を使うヒューリスティック。GTO解ではない。12BB以下はプッシュに変換する簡略化。混合戦略や相手戦略、フォールドエクイティは解かない。通常のフリーズアウト想定。

計算はブラウザ内、入力情報は保存・送信しない。Google Fontsへのフォント通信あり。
計算根拠はアプリ下部。参考: https://arxiv.org/abs/0911.3100

初期チップ量（デフォルト30,000）、現在のSB（5,000）・BB（10,000）は基本入力に表示。BB変更はレンジ表のBB深度へ即時反映。SBはBB以下。SBの非標準比率によるレンジ調整は行わない。

賞金配分の参考資料: https://www.wsoponline.com/nv/how-to-play-poker/mtt-tournament-payouts/

賞金総額は自動計算欄に表示し、バイイン×総エントリー数に常時連動。手動の総額入力欄は廃止。

## GitHub Pagesの更新
mainブランチに変更を反映し、`git subtree push --prefix dist origin gh-pages` で公開ファイルを更新します。Pagesはgh-pagesブランチのルートを配信します。

「1BB増えた場合のプラス賞金期待値」は現在のBB分を他の全員から比例移転した状態でICMを再計算した差額。BB変更に連動。相手総チップ不足では表示不可。

±1BB比較バーは増加側と減少側のICM差額を同じ円スケールで表示。減少側は相手全員へ比例移転し、損失÷利益の倍率を表示。自分の残りが1BB未満のときは減少側は計算不可。

カードは初めて画面内へ入ったときに短くフェードイン。計算結果は即表示し、更新箇所をハイライト。±1BBバーは中央から展開。OSの「視差効果を減らす」設定では動きを無効化。外部ライブラリなし。

入力時の枠と自動計算値のハイライト、ボタンの操作反応、ポジション切替時のハンド色の遷移を追加。レンジセルの要素を再利用し、色のみ滑らかに変化させる。

## オープンレンジの出典
外部チャート・GTOソルバー・実戦データの取得や読み込みは行っていません。ポジション基準（UTG14%、LJ21%、HJ25%、CO32%、BTN47%、SB52%など）と補正係数は、このアプリ内で定義した独自の仮定です。ペア・高カード・スーテッド・連結性を独自スコア化し、目標頻度までコンボ順に選択します。ICMからレンジへの補正も独自のヒューリスティックで、均衡戦略として検証されていません。賞金配分のWSOP参考資料はレンジの出典ではありません。

画面は補助ラベル・重複説明を抑え、入力グループと余白で構成。計算の根拠・詳細は「計算について」に集約。
